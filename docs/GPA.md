## Desempenho Acadêmico

- GPA: Média de Notas em uma escala de 2,0 a 4,0, influenciada por hábitos de estudo, envolvimento dos pais e atividades extracurriculares.
  
## Variável-Alvo: Classe de Nota

- GradeClass: Classificação das notas dos alunos com base no GPA:
- 0: 'A' (GPA >= 3,5)
- 1: 'B' (3,0 <= GPA < 3,5)
- 2: 'C' (2,5 <= GPA < 3,0)
- 3: 'D' (2,0 <= GPA < 2,5)
- 4: 'F' (GPA < 2,0)
